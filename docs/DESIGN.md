# Remocon 디자인 기준

디자인 개편(0.2)은 **[design/spotify-reference.md](design/spotify-reference.md)** 를
기준으로 합니다. 이 문서는 그 기준을 Remocon에 맞게 옮긴 규칙입니다. 둘이 다르면 이 문서가
우선합니다. 여기 없는 내용은 레퍼런스를 따릅니다.

레퍼런스에서 가져오는 것은 시각 언어(색, 형태, 밀도, 깊이)뿐입니다. Spotify의 이름,
로고, 전용 폰트는 쓰지 않습니다.

## 1. 핵심 원칙

- **콘텐츠 우선 어둠**: UI는 거의 검은 회색 단계로만 만들고, 색은 내용(세션 상태, 에이전트
  종류)에서만 나오게 합니다. 레퍼런스의 "앨범 아트" 자리가 Remocon에서는 세션입니다.
- **포인트 색은 하나**: 그린 `#1ed760`은 기능에만 씁니다. 주요 실행 버튼(새 세션, 이어가기),
  활성 상태, 실행 중 표시에만 쓰고, 장식이나 배경에는 쓰지 않습니다.
- **알약과 원**: 모든 버튼은 알약 모양, 아이콘 버튼은 원형입니다. 각진 버튼은 쓰지 않습니다.
- **촘촘하게**: 작업 도구이므로 글자 10–24px, 좁은 줄 간격, 8px 간격 단위를 씁니다.
- **어두운 테마만**: 라이트 테마는 만들지 않습니다(이전 로드맵의 라이트/다크 전환 항목은 뺐습니다).

## 2. 디자인 토큰

`web/assets/tokens.css`의 `:root`에 정의하고, 다른 CSS는 토큰만 참조합니다.

```css
:root {
  /* 표면: 깊이는 명도로 */
  --bg:          #121212;  /* 레벨 0, 페이지 */
  --surface:     #181818;  /* 레벨 1, 사이드바·카드 */
  --surface-2:   #1f1f1f;  /* 버튼·입력·인터랙티브 */
  --surface-3:   #252525;  /* 떠 있는 카드, hover */
  --surface-4:   #272727;  /* 대체 카드 */

  /* 텍스트 */
  --text:        #ffffff;
  --text-2:      #b3b3b3;  /* 보조, 비활성 내비 */
  --text-3:      #cbcbcb;  /* 조금 밝은 보조 */

  /* 포인트 · 의미 */
  --accent:      #1ed760;  /* 기능 전용 */
  --accent-edge: #1db954;
  --on-accent:   #000000;
  --negative:    #f3727f;  /* 오류, 삭제 */
  --warning:     #ffa42b;  /* 경고, 계정 불일치 */
  --info:        #539df5;  /* 안내 */

  /* 선 */
  --line:        #4d4d4d;  /* 어두운 바탕 위 버튼 테두리 */
  --line-2:      #7c7c7c;  /* 외곽선 버튼 */

  /* 그림자 */
  --shadow-1:    rgba(0,0,0,.3) 0 8px 8px;   /* 카드, 드롭다운 */
  --shadow-2:    rgba(0,0,0,.5) 0 8px 24px;  /* 대화상자, 메뉴 */
  --inset:       rgb(18,18,18) 0 1px 0, rgb(124,124,124) 0 0 0 1px inset; /* 입력 */

  /* 모서리 */
  --r-badge: 2px; --r-input: 4px; --r-card: 6px; --r-section: 8px;
  --r-panel: 12px; --r-pill: 9999px; --r-circle: 50%;

  /* 간격 (8px 기준) */
  --s-1: 4px; --s-2: 8px; --s-3: 12px; --s-4: 16px; --s-5: 20px; --s-6: 24px;
}
```

## 3. 글꼴

Spotify 전용 폰트는 쓸 수 없고, 한국어가 기본 언어이므로 한글 폰트를 앞에 둡니다.

```css
--font: "Pretendard Variable", Pretendard, -apple-system, BlinkMacSystemFont,
        "Apple SD Gothic Neo", "Malgun Gothic", "Noto Sans KR",
        "Helvetica Neue", Helvetica, Arial, sans-serif;
--mono: ui-monospace, "SF Mono", "Cascadia Code", Consolas, monospace;
```

Pretendard는 jsdelivr CDN에서 버전을 고정해 불러오고, 실패하면 시스템 폰트로 대체합니다.

| 역할 | 크기 | 굵기 | 쓰는 곳 |
|---|---|---|---|
| 섹션 제목 | 24px | 700 | 폴더 화면 제목 |
| 소제목 | 18px | 600, 줄 간격 1.3 | 대화상자 제목 |
| 본문 굵게 / 본문 | 16px | 700 / 400 | 세션 제목, 미리보기 |
| 버튼 | 14px | 700 | 모든 버튼 |
| 내비 | 14px | 활성 700 / 비활성 400 | 사이드바 폴더 |
| 캡션 | 14px | 400 | 경로, 시간 |
| 작은 글씨 | 12px | 700 / 400 | 세션 수, 태그 |
| 배지 | 10.5px | 600 | live, 에이전트, 계정 |

- 굵기는 700과 400을 기본으로 하고 600은 아껴 씁니다.
- **대문자 + 자간(1.4px)** 은 영어 UI의 버튼 라벨에만 적용합니다. 한글 라벨은 자간 0을 유지합니다.
- 경로와 세션 ID는 `--mono`로 씁니다.

## 4. 컴포넌트 대응

| Remocon 요소 | 레퍼런스 컴포넌트 | 규칙 |
|---|---|---|
| 새 세션 · 이어가기 (주요 실행) | Circular Play + 그린 | `--accent` 배경, 검정 글자, 알약형 또는 원형 |
| 일반 버튼 (머신 추가, 새로고침 등) | Dark Pill | `--surface-2`, `--r-pill`, 8px 16px |
| 보조 버튼 (포크, 미리보기) | Outlined Pill | 투명 배경, `1px solid --line-2` |
| 아이콘 버튼 (⋯, 삭제, 새로고침) | 원형 | `--r-circle`, 32px, hover 시 `--surface-3` |
| 위험 버튼 (삭제, 중지) | Dark Pill + 의미 색 | 글자만 `--negative`, 확인 대화상자에서만 빨간 배경 |
| 검색창 | Search input | `--surface-2`, `--r-pill`, 왼쪽 아이콘, `--inset` |
| 사이드바 | Navigation | `--bg` 배경, 활성 폴더는 흰색 700, 나머지 `--text-2` 400 |
| 세션 카드 | Card | `--surface`, `--r-card`, 테두리 없음, hover 시 `--surface-3` + `--shadow-1` |
| 대화상자 (미리보기, 계정, 머신 추가) | Dialog | `--surface`, `--r-section`, `--shadow-2`, 뒤 배경 `rgba(0,0,0,.6)` |
| 입력 · 셀렉트 | Input | `--surface-2`, `--r-input`, `--inset`, 포커스 시 `--text` 외곽선 |
| 토스트 | Elevated | `--surface-3`, `--r-section`, `--shadow-2` |

## 5. 색이 내용에서 나오는 곳

UI 자체는 무채색이고, 아래 상태 표시에만 색을 씁니다.

| 내용 | 표시 |
|---|---|
| 실행 중(live) 세션 | `--accent` 점 + "live" 배지 |
| Claude 세션 | 에이전트 배지 `#d97757` (작은 점 또는 배지에만) |
| Codex 세션 | 에이전트 배지 흰색 외곽선 (그린은 포인트 색과 겹쳐서 쓰지 않음) |
| 다른 계정으로 연 세션 | `--warning` 배지 |
| 오프라인 머신 · 실패 | `--negative` 점 |
| 터널 연결 중 | `--info` 점 |

에이전트 색은 레퍼런스에 없는 색이지만, 앨범 아트처럼 "내용의 색"으로 보고 배지 크기에만 씁니다.

## 6. 레이아웃 · 반응형

- 데스크톱: 고정 사이드바(머신 → 폴더) + 본문(세션 목록) + 하단 상태 바.
  하단 상태 바는 레퍼런스의 now-playing 바 자리로, 진행 중인 실행·배포와 터널 상태를 보여줍니다.
- 세션 목록은 촘촘한 리스트(트랙 리스트 방식)를 기본으로 합니다.

| 폭 | 사이드바 | 본문 |
|---|---|---|
| ≥ 1024px | 전체 (280px) | 리스트 |
| 768–1024px | 접힘 (아이콘 + 머신 점) | 리스트 |
| < 768px | 숨김, 하단 탭 바 (머신 / 폴더 / 검색 / 설정) | 한 단계씩 화면 전환 |

## 7. 하지 말 것

- 그린을 장식, 배경, 큰 면적에 쓰지 않습니다.
- 밝은 배경 면을 만들지 않습니다.
- 각진 버튼을 쓰지 않습니다.
- 회색 테두리를 그대로 드러내지 않습니다. 그림자나 inset으로 경계를 만듭니다.
- 얇은 그림자를 쓰지 않습니다(어두운 바탕에서는 보이지 않음).
- 포인트 색을 더하지 않습니다.
